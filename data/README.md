# 📊 Dados

Este diretório documenta o dataset utilizado no projeto de previsão de churn.

## Estrutura esperada

```text
data/
└── raw/
    └── telco_churn.csv
```

O dataset não é versionado neste repositório. Antes de executar o pipeline, coloque o arquivo CSV na pasta `data/raw/` conforme as instruções do projeto.

## Variável-alvo

A variável `Churn` representa se o cliente cancelou o serviço.

- `Yes` → cliente cancelou
- `No` → cliente permaneceu
